# Architecture Decision Records

One file per decision, numbered in order. Each record has a status, the context that forced the decision, the decision itself, and its consequences. When a decision changes, add a new record that supersedes the old one rather than editing it.

To add one, copy `template.md` to `NNNN-short-title.md` using the next number, fill it in, and add a row below.
